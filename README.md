# Omon (欧蒙)
> “我们不租借数字生命，我们拥有它。”
### 0. 为什么要有 Omon？
现在的互联网像是一座座围墙花园，大平台是房东，我们只是交出隐私换取居住权的租客。一旦房东不高兴，你的社交关系、数字资产和珍贵记忆都会被瞬间抹除。
Omon (欧蒙) 不是要做一个更好的 App，而是要提供一种**“数字维度的防御力”**。
### 1. 三大核心支柱
* **身份主权 (Monad ID)**：
  抛弃那些该死的私钥和密码。你的身体就是唯一的通行证。通过生物特征与社交恢复（亲友验证）锁定身份，只要你还在，你的数字生命就在。
* **刻律协议 (Chroma-Lex)**：
  让承诺回归它本来的样子。在 Omon 里的契约是自动执行的代码，无需中间人，没有“赖账”这个选项。
* **仁慈共识 (Mercy Protocol)**：
  代码不应该是冷血的。我们设计了志愿者仲裁机制，允许在极端情况下通过社区共识给予容错，这才是人类社会。
### 2. 这里的规则
* **没有中间商**：没有公司能看你的聊天记录，没有机构能冻结你的钱包。
* **数据交织**：你的数据碎化在无数节点中，像野草一样，火烧不尽。
* **无感交互**：所有的去中心化黑科技都隐藏在极简的交互之下，你只需要像往常一样生活。
